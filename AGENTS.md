# TAMU Topdown

Use typed GDScript and the Compatibility renderer. Keep Android as the target.
Do not import old TAMU scenes, scripts or art. Reuse game data and rules only after verifying the source and preserving stable IDs.
Ste’s Project is a reference, not an upstream to merge. Keep integrations narrow; never allow two inventories or two sources of save state.
Read SESSION_HANDOFF.md before changing the project. Report static checks, headless tests and Android verification separately.
