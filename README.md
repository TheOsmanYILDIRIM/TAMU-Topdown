# TAMU Topdown

Independent Godot 4.7.2 top-down rebuild of TAMU, targeting Android with typed GDScript and the Compatibility renderer.

Open `project.godot` and press F5. Use the arrow keys or tap/click the floor to move. Tap the chest or tree to select that specific object; the label reports whether it is in range. The room uses temporary geometric shapes. No inventory, harvesting or persistence is connected yet.

Ste’s Project ([reference commit](https://github.com/stesproject/godot-2d-topdown-template/tree/ea95789514fe28532d4ed444bdd06a9d4cddad31)) informed the separation of movement and interaction. This is not a fork and does not ship its demos or assets.
